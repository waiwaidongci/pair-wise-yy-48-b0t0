# 消防报警系统联动逻辑配置与调试审阅平台

面向消防工程师、调试人员和审阅人的联动逻辑工作台，支持设备台账、因果矩阵、互锁/延时/优先级配置、矩阵校验、**联动推演**、依赖图、版本差异、联调清单和签字锁定。

## 技术栈

Vue 3 + Vuetify + Pinia + Vue Router + Apollo Client + GraphQL + Vite + TypeScript

## 本地运行

```bash
npm install
npm run dev
```

访问 `http://localhost:62048`。

## 核心工作流

- 按楼层分区维护探测器、模块和消防设备，建立触发到动作的因果矩阵。
- 配置延时、互锁、优先级和抑制条件，并批量启停或修改矩阵规则。
- 自动发现遗漏、重复、自相矛盾和跨区冲突，在依赖图中定位问题。
- **联动推演**：选择报警点与故障设备，按启用规则、延时与优先级排出带时刻的执行序列：
  - 故障设备记为“拒动”，其后续规则停止推进并在“故障阻断路径”中列出；
  - 联锁反馈未到达的规则停在“等待”（含联锁回路未闭合提示）；
  - 时间轴可播放，标出成功 / 等待 / 拒动；规则或设备改动后旧结果立即失效，需重新推演。
- 比较专业提交版本并部分接受变更，完成联调清单后签字锁定交付包。

## 分层约定

- `src/linkage/` —— 纯领域层：`types.ts`（模型）与 `engine.ts`（推演纯函数、联锁反馈解析、结果签名），不依赖 Vue/Pinia。
- `src/stores/` —— 状态层：`linkage.ts`（设备/规则/校验）与 `simulation.ts`（报警点、故障设备、推演结果、播放时刻）。
- `src/views/` —— 页面层：只做选择、渲染与播放计时，推演算法全部在引擎中，可直接用 Node 单测调用。
